# Chapter responsibilities and evidence-dependent writing

Project coordination synthesis informed by the sources in [source-ledger.md](source-ledger.md). Use for substantial revision/integration; a small edit needs only its affected dependency. Team size and printed headings are independent choices.

The editor maintains the common argument: object/question → established knowledge → unresolved distinction or explanatory need → design/argument → evidence → bounded answer. Give section owners a compact packet containing that argument, actual evidence/counterevidence, object/comparator definitions, useful original locators, adjacent outgoing/incoming points, paths and return conditions. Preserve authorization; source learning does not expand the study.

| Responsibility | Necessary return and dependency |
| --- | --- |
| Source/lineage work | Establish closest achievements and supported unresolved aspect; editor interprets before drafting uses it |
| Methods | Define design, quantities, conditions, roles and checks; evidence owner confirms reported contrasts follow it |
| Results/interpretation | Answer named questions from actual evidence and alternatives; Methods owner checks definitions/design |
| Introduction | Earn the question and route from lineage, matching actual work and conclusion |
| Discussion/conclusion | Develop changed understanding and limits; distinguish explanation from observation |
| Title/abstract | Condense the integrated supported answer, not just an early plan |
| Review | Inspect actual integrated prose/displays, locate defects and recheck repair |

These responsibilities may be combined. For MAF, Methods-only ownership can use `methods_results`; an owner of combined Results and Discussion can select `methods_results` and `discussion_conclusions`. Assigned paths and purpose delimit actual ownership. No separate chapter scheduler is implied.

Across adjoining sections agree on the main explanation location and what recall adds: definition, evidence, qualification or synthesis. Owners read actual boundary passages together. Methods and evidence owners reciprocally check consequential quantities, units, varied/held factors, baseline, data roles and locators. Report discrepancies in existing notes rather than require another form.

For whole-manuscript revision inspect a reverse outline of headings and paragraph controlling points. It should reveal the reasoning route; matching headings and fluent standalone sections do not establish it. Use selected [section decisions](section-specific-guidance.md) for chapter jobs and [object diagnosis](object-and-continuity.md) for weak links.

Order support by dependence. Definitions and actual necessary check outcomes are available before or beside the inference relying on them, with precise references when details are elsewhere. The checks depend on claims: numerical accuracy, measurement reliability, physical transfer or theoretical consequence need different support. A run label or planned test is not an adequacy result. When support is missing use [constructive supplementation](evidence-supplement.md).

When venue/source learning is assigned, return current author instructions, comparable passages actually read, applicable requirements, observed conventions and justified adaptations. Distinguish unavailable full texts and abstract-only access. Make originals and manuscript retrievable for authorized human review; requested/pending review is not received approval. Scientific support and editorial acceptance remain separate, and new counterevidence reopens affected claims.
