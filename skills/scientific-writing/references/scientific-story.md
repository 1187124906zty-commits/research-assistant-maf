# MAF writing handoff

Use the maintained `research-writing-skill` entry selected by the role loader. Its workflow and writing decisions apply to the actual assignment; MAF supplies the task contract, source paths and requested output paths.

Preserve `task.writing.mode` (`draft`, `revise`, `audit`) and `task.writing.sections` (`title_abstract`, `introduction`, `methods_results`, `discussion_conclusions`, or `full_manuscript`). The coordinator retains research-state decisions; writers return assigned prose and reviewers return located findings. This reference adds no writing rules, mandatory review stack or runtime controller.

The loader reports the actual entry path. Read its needed references in place. If the implicit entry is unavailable, use the existing bundled fallback rather than claiming that the maintained skill was loaded.
