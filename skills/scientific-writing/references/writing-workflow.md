# 面向科研智能体的论文写作指导：从原始指南到可执行判断

本轮得到的是一套有原件定位、可供智能体复用的写作判断方法，不是对某份论文完成的质量认证。共阅读12份实质指南页面，来自MIT/Broad/CEE、曼彻斯特大学、UNC教堂山分校、PLOS学者文章和USC图书馆5个来源组。完整身份、实际读取范围、短引文、原文位置、许可和迁移边界见[source-ledger.md](source-ledger.md)；具体章节流程与原创示例见[section-specific-guidance.md](section-specific-guidance.md)。写作教学来源与研究论文的科学参考文献分开管理。

## 共同认识与不能机械执行的部分

这些原始指南支持的核心是：让读者识别论文回答的问题、理解证据怎样支持回答、判断这个回答的适用范围。标题、摘要、引言、方法、结果和讨论共同服务这一认识，而不是按任务执行顺序汇报作者做过什么。MIT Methods强调足以判断有效性和复现的必要细节；UNC强调精确用词、段落控制思想和真实逻辑联系；PLOS强调中心贡献及结果的证据顺序。写作的“客观”来自可核对的事实、推理与范围，不由被动语态或不断添加免责声明制造。

| 原始指导与可用部分 | 迁移时必须保留的边界 |
|---|---|
| [MIT/Broad Abstract](https://mitcommlab.mit.edu/broad/commkit/journal-article-abstract/)：从实际结果中删减、合并，保留关键结果及其认识意义。 | 六个组成部分、建议句数是教学模型；不制定“只能两个数”、固定六句、一定正向改善等要求。 |
| [MIT/Broad Introduction](https://mitcommlab.mit.edu/broad/commkit/journal-article-introduction/)：前面的背景应使当前问题成为合理的下一问。 | 四个组成部分不等于四段；无需每段结尾都写研究空白，专业期刊也可能从具体问题直接进入。 |
| [MIT/Broad Methods](https://mitcommlab.mit.edu/broad/commkit/journal-article-methods/)：保留影响结论的设计细节，并说明方法为什么匹配问题。 | “避免we”的建议与UNC对主动语态的接受并不一致；按科学主语、清晰度及实际期刊要求选择。 |
| [Manchester Introducing work](https://www.phrasebank.manchester.ac.uk/introducing-work/)：CARS与功能分类帮助辨认上下文、缺口和目的。 | 原页明确说顺序不固定、并非所有元素都出现；句型库不是对“没有研究”“提高性能”等断言的事实支持。 |
| [UNC Paragraphs](https://writingcenter.unc.edu/tips-and-tools/paragraphs/)：统一、充分展开的控制思想定义段落。 | 段落不由句数或长度定义；主题句可以不在首句，收束可以是结论或自然过渡。 |
| [UNC Transitions](https://writingcenter.unc.edu/tips-and-tools/transitions/)：衔接显示已有的逻辑关系；先检查组织，再选择连接词。 | 添加however/therefore不能修复缺失证据或不存在的因果关系；不要求每段有显式路标。 |
| [UNC Scientific Writing](https://writingcenter.unc.edu/tips-and-tools/sciences/)：精确名词、明确主语和动作、必要细节与结论范围。 | 保持准确的重复术语优于装饰性换词；复杂句和介词数量建议不是自动判错阈值。 |
| [Mensh与Kording，PLOS](https://doi.org/10.1371/journal.pcbi.1005619)：标题体现中心贡献、摘要讲完整故事、结果按证据逻辑排列。 | CCC及“gap”结构是作者倡导的默认模式；不复制成每段统一模板，不把一个贡献等同于一个算法或一项改善。 |
| [MIT CEE Journal Article](https://mitcommlab.mit.edu/cee/commkit/journal-article/)与[USC Choosing a Title](https://libguides.usc.edu/writingguide/title)：标题联系主旨、使用领域名称、说明主题和范围。 | USC的5–12词、标题式大写及社会科学例子是其惯例，不能作为其他期刊规则。具体术语搭配须读领域原件，大学指南不会替某个搭配背书。 |

## 从论证到章节的工作流程

1. **先恢复当前问题和真实结论。** 协调者读取最新证据、反证、已接受范围和用户偏好，写一句“本研究在何种条件下回答什么，证据显示什么”。结果可以是改善、无明显改善、方向相反、方法失效条件、适用性或解释上的区分。不得先选择“提高性能”的叙事，再寻找数字填充。
2. **确定读者需要知道什么。** 用目标期刊范围、相近论文和当前作者指南确定读者与合规要求。将正式要求、样本文体惯例、教学启发和项目偏好分别记录。写作教学来源不进入研究文章的科学参考文献，也不增加论文证据数量。
3. **建立最小论证提纲。** 每个单元写科学问题、可用证据、能推出的判断和下一个必要问题。把方法/图表/比较放到支持该判断的位置；先改结构，再改表达。不要把“一个段落一个作用”误解为不允许一段中有证据、解释和必要限定。
4. **分配信息。** 正文放影响读者判断的模型、控制、参数角色、观察定义、比较和主要误差证据；附录展开推导、观察算子和必要补充检验；复现记录保留命令、依赖、配置与路径。移动必须留下可用关联位置，不能删除决定性细节或承诺不存在的公开包。
5. **形成标题、摘要与引言。** 从已确定结论选择标题关系和摘要关键证据；引言综合已有认识，推导本研究问题。阅读摘要与引言时，读者不需要知道智能体分工、文件检查或内部工具名称。
6. **检查段内与段间推理。** 反向提纲写出每段的控制思想和证据；相邻段落之间标明具体关系：进一步限定、原因、可比性、反例、尚未解决的下一问等。如果只能说“再谈另一篇论文”，通常需要重组综合，而不是加连接词。
7. **按证据核对语言。** 对比修改前后数值、单位、否定、因果、条件、引用归属与结论强度。校准、验证、预测、测量、执行与派生量不能互换。明白的原文可以保留；停止为节奏而改同义词。
8. **让另一名读者检查实际产物。** 给评阅者当前源码、图表和相关原件，而不是仅给作者的诊断。输出定位问题、最小修复与尚缺的证据；协调者解释接收/部分接收。写得顺畅不提升物理证据等级，语法检查不代替阅读。

## 适合分派给智能体的问题

| 责任 | 有意义的有限问题 | 输入与返回 |
|---|---|---|
| 协调者/科学编辑 | 论文当前的中心认识是什么？哪个证据区分了它？读者在哪一处失去前提？ | 当前证据、全文与偏好；返回论证顺序、改动优先级和具体章节任务，不改用新主张掩盖反证。 |
| 文献智能体 | 引言综合的共同认识是否成立？标题术语在最相关领域论文里是什么意思？某个“空白”是否被已有工作反驳？ | 指定句子、近邻原件、搜索边界；返回原件页/节、条件、可支持范围和可比性，不能只报题名相似。 |
| 证据/计算智能体 | 比较、参数、误差和校准角色的定义是否完整？缺失信息影响哪一条结论？ | 数据/代码/计算记录与命名论断；返回真实比较、可用精度和依赖，不把执行成功标成物理验证。 |
| 机制智能体 | 结果支持的是模型内解释还是物理因果？哪些替代解释仍成立？ | 实际结果、控制和机制原件；返回解释层级、反证与一个有判别力且可实施的补证问题。 |
| 写作智能体 | 当前段落/章节承担什么科学作用？如何用已有证据完成该作用并接上相邻单元？ | 固定稿件与已核对来源；返回完整替换段/节及事实不变量检查，避免只交付建议。 |
| 独立评阅智能体 | 修改后的原文和页面是否解决命名问题？是否引入了新因果、搭配歧义或数据失真？ | 新旧版本、原件、图表；返回可定位的缺陷与修复核验，不能按工具PASS或作者自评通过。 |

不要为了写作指南临时启动所有角色。语法问题可直接修；涉及科学意思的搭配交文献/机制核对；额外计算仅用于会改变论断的缺口，不能为正向故事追求显著性。

## 用户偏好的科学边界

“更自信”“摘要说明意义”“少写不是/不属于”“方法更客观”可以提高可读性，但都不授权改变结果。未改善的比较不能写成改善；未隔离的部件不能写成造成提升；没有检验零效应不能写成证明无效。可以说明负结果排除了哪个具体方案、指出了什么补偿或限制，但不能凭写法把它变成普遍规律。

减少防御句的操作是先回答“实际做了什么、量怎么定义、数据承担什么角色”，然后在会改变解释的地方留下清晰限定。明确哪些数据参与估计、哪些用于后续比较，以及比较保留了哪些设置。若所有目标在开发时已知，仍要客观披露回顾性、非盲比较；参数关系超出来源适用范围时，说明处理依据及假设。软件身份、AI披露、作者责任、数据范围及伦理事实按真实情况和期刊要求保留；删去工作流宣传不等于隐瞒研究过程。

## 停止与有限返回

当指定标题/摘要/章节能使读者识别问题、跟上证据、理解范围，并且科学不变量及关联来源已核对，就交付实际文本。可选措辞修改如果不再改善理解，应停止。两次同一修饰仍未解决问题，指出缺的是结构、原件、事实还是任务定义，由协调者重定向；不能反复美化后宣布解决。

缺少证据时返回一个有边界的问题、它影响的句子以及较便宜的替代办法。区分对数据处理或观察定义的核查与取得新的独立证据：前者能排查比较差异，却不自动完成后者的证据角色。缺少搭配依据时返回具体术语和误读，不因语法正确便批准科学含义。未知的期刊规则不妨碍安全改稿，但不能宣称符合该规则。
