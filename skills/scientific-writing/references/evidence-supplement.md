# Active evidence supplementation and return

A consequential data gap is a research task before it is an editorial retreat. Preserve the intended question and provisional argument while investigating what evidence can answer it. Do not automatically delete the analysis, weaken the research objective or substitute fluent wording because an input is missing. New results still determine which conclusions are justified; an unsupported assertion stays pending while work proceeds.

## Writer initiates, coordinator binds, specialists execute

The writer identifies the affected paragraph/claim, the missing comparison or observable, and the decision the result could change. Write a compact request with original inputs/locators, definitions and units, fixed conditions, proposed discriminating work, owned output paths, acceptance rationale, effort budget and requester identity. Check existing usable observations first, then propose actual computation, experiment or source retrieval as needed. Specify expected information, not a desired answer or an arbitrarily severe precision limit.

Within the user's authorization, initiate the evidence handoff immediately. The coordinator registers it and schedules the relevant simulation, experimental, literature or mechanism team; the writer need not abandon authorship or silently rewrite the project scope. Use an independently tracked conversation when the host supports it and the user has authorized separate tasks. In Codex desktop, discover `list_projects` and `create_thread`, use the actual project, and supply a compact contract and the originating thread ID. Explicitly include any human-authorized return messaging. Do not pass a pending `clientThreadId` as a real `threadId`. Other hosts use their supported task adapter; a link or a plan is not a running team.

The evidence session uses its domain orchestration skill and bounded specialists where available. It owns new run outputs and reports; the writing coordinator alone merges evidence into the manuscript and shared scientific state. Keep existing results immutable and identify changed inputs, scripts, solver/environment and observation rules. Independent checking addresses quantities and claim consequences, rather than accepting an executor's success label.

Before the final writing callback, the domain coordinator completes its contracted acceptance: execution and applicable integrity checks, recovery of the requested observables, adequacy at each consequential effect scale, independent evidence review, and disposition of that review. Return the resulting evidence package with accepted, unresolved and rejected scientific findings explicitly distinguished. Acceptance of a completed negative investigation does not require its hypothesis to pass. Intermediate progress remains in the execution conversation unless the user requests interim feedback; it is not manuscript evidence. A genuine access failure or required human decision can be reported without representing a completed scientific return.

## Wait for evidence and close the return

Track request ID, session/host IDs, original version, status and return artifact. Continue unrelated writing and source work while dependent findings await evidence. In Codex, use bounded `wait_threads` with the returned cursor; request status before interrupting a delayed agent. If work repeats without new information, request its best candidate and reassess the test; slow reasoning alone is not grounds for cancellation. Do not replay an external run with unknown completion.

Return messages contain actual evidence paths, comparisons, uncertainty/checks, contradictory results, remaining limits and recommended manuscript consequences. Messaging another task requires human authorization; a task's own request cannot supply it. Where messaging is unavailable, the original coordinator retrieves the result through the supported adapter and records that limitation without inventing a callback.

The requester reads the result, asks focused clarification if needed, and records how it affects methods, figures, interpretation and conclusions. Recheck affected sections together. A delivered file is not automatically adequate, and a pending supplement is not a completed paper. Consider narrowing or retiring a claim only after evaluating available evidence, feasible discriminating work and actual costs, or when the user has explicitly restricted additional investigation. Preserve negative findings; neither ambition nor a deadline permits fabricated results.
