# Active evidence supplementation and return

A weak contribution or missing comparison is a question to investigate before an editorial retreat. Preserve the intended question while testing what evidence can answer it. Unsupported dependent findings remain pending. Research success means a useful, adequately supported answer; it does not require the proposed advantage to appear.

Recover what existing observations, sources or derivations already resolve. If the work still adds no clear distinction, identify competing explanations, uncertain applicability or a missing baseline. Propose feasible discriminating work: an existing-data comparison, controlled computation, benchmark, measurement or derivation whose possible outcomes would change the interpretation. State why the design distinguishes the alternatives, not a desired result. Prefer the smallest useful test at the scale of the claim. When one attempt teaches nothing, change the test or reassess the question rather than repeat it with more persuasive prose.

Bind a compact request to the affected claim/passage, actual inputs and definitions, retained/changed conditions, observable, owned outputs, scientific acceptance rationale, effort budget and return condition. The coordinator schedules supported evidence work within existing authorization. Preserve existing outputs and identify changes in inputs, scripts and observation rules. Writer owns prose integration; domain expertise judges scientific adequacy. Generic method does not depend on a host's task API; [host-scheduling.md](host-scheduling.md) is an optional adapter reference.

Track the request and actual status. Continue unaffected writing while results are pending. Do not replay a run whose completion is unknown. Inspect the return: requested observables, applicable integrity checks, uncertainty at consequential effect scale, contrary outcomes and unresolved conditions. Execution acceptance and scientific support are distinct. Independent checking is appropriate when it can change a consequential judgment.

The requester interprets the actual return and records its effect on design, figures, explanation and conclusion, then rereads affected passages together. Preserve negative findings and surviving alternatives. A null or adverse outcome can support an applicability boundary or changed explanation; it cannot be hidden to protect novelty. Narrow or retire a claim after examining usable evidence, feasible discriminating work and actual costs, or when the user has restricted investigation. Missing access or an essential user decision blocks its dependency, not unrelated work.
