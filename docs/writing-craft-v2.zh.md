# 通用写作指导与上下文范例的第二轮重构

这轮重构把默认指导从重复协议和项目条件转向读者问题、对象引入、段落推进与完整示范。熔池工况、相界和材料函数留在案例输入；通用skill适用于理论、方法、综述和不同工程领域。

## 交给不同角色的内容

协调者提供研究问题、目前证据、希望形成的贡献、竞争解释、相邻段落关系和写入目录。补证任务回答实际科学问题，不保证有利结果。写作者按章节读取简短通用指导、完整教学段落及少量适用的来源范例；它们解释如何写，不提供本研究数据。审查者读取实际整稿与图表，重建论证、核对比较和数据角色，提出可定位的实质修复。图表任务先明确读者应作何判断，再选择对照、尺度、色彩和符号。

`load_role` 为明确的写作任务提供章节范围的精简说明，完整技能接口仍可按需读取。工具字段与宿主调度接口分别进入 `library-adapter.md` 和 `host-scheduling.md`；逆问题、择优样本等检查进入 `task-type-checks.md`，按实际任务使用。

## 如何学习来源

`source-backed-exemplars.md` 包含六篇有目的选择的来源：Nature Physics、Nature Communications、npj Computational Materials、CCR、CMAME。每张卡保留 DOI、实际章节与页码，解释原段落怎样推进、图表怎样对照、哪些条件不能迁移。推荐使用章节与原文章节分开。例如某篇 Results 开头的模块介绍可用于学习 Methods 的对象引入，但不能把其原文章节改写为 Methods。

卡片中的教学段落为新编假设示范。学习的是论证动作和表达关系，而不是把来源结果移植到当前稿件。期刊声望、关键词匹配、填完槽位或软件测试通过，都不能替代科学与阅读判断。

## 实际验证范围

相同调用范围的全文 writer 指导由 106,050 字符减为 49,498 字符；Introduction 由 56,010 减为 29,605。当前改动通过 111 项标准测试、skill 校验、两轮真实离线 demo、打包与独立目录的安装包调用。它们检验资源交付和执行路径，不证明文风效果或科研收益。

另有理论段落和 AMMT 开头的真实前向使用，以及不同生产者完成的整稿重写和另一个角色的实际源码评阅。生产者练习不是独立质量结论；同模型角色也不构成统计独立实验。前向使用发现的边界条件与原文章节错误已修复。最终文稿的科学结果、图表和阅读审查在案例交付中分别记录。

## 对正向贡献的要求

证据不足时，应主动调查有信息价值的补充比较或推导，并回收真实结果修订论证。贡献可以是准确性改善，也可以是解释被区分、有效评估变量被找到或适用条件被确定。性能改善需公平比较和独立评价；宽度改善而深度恶化属于权衡，不能写成整体精度提升。

当前 skill 不规定摘要固定首句、每节固定段落数、通用图文比例或始终有利的结果。验收针对问题、证据与读者能否理解的实际关系。
