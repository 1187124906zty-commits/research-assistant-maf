## 2. 将三种问题分开

此前“在固定传导模型中，长度拟合、高温物性延拓和派生热历史之间有哪些约束”适合作为内部证据任务，过早放在论文动机层会让读者先看到分析变量，尚未看到科学必要性。修改句尾为“尚未探明”仍不能解决层级过窄的问题。

| 层级 | 职责 | 本案例的工作定位，不是已定稿结论 |
|---|---|---|
| 领域困境 | 先建立读者关心的用途、落差和后果 | 可观测几何的一致性不能充分约束热状态解释；这影响对模型所描述热状态与凝固过程的判断。前半句有已读文献支持，不是本文新增发现。 |
| 具体知识缺口 | 从近期最接近研究中确定仍未分辨的关系及其原因 | 几何标定之后，未充分表征的物性与模型假设对派生热过程认识的影响，需要在可比观测和固定标定条件下分辨。到底哪些部分尚未解决，必须由近期原文研究修订。 |
| 技术检验与设计 | 将知识缺口落实为可执行、可证伪的比较 | B 长度单目标标定、冻结源参数、分别改变高温 k/cp 续接、比较几何和后相界，再分析空间特征与材料经过时间。这些在引言末段简要出现，在 Methods/Results 充分展开。 |

这三个层级相互约束。大层问题决定分析为何值得做，原始研究与结果反过来决定本文能回应到何种程度。不能由已有运行清单倒推出一个正好迎合结果的世界级 gap，也不能选择一个过大的问题再靠摘要掩盖未完成的验证。

面向读者的 gap 采用用户偏好的**陈述式表达**：对象/关系 + 已有知识下仍未解决的部分 + 原因/后果。内部调查可以继续用为什么/如何/哪些，因为它们用于派发与检验。问句不是普遍学术禁令，但本稿的主问题不写成工具使用问答。

“尚未探明、悬而未决、仍不明确、仍是一项挑战”的强度要由已有文献决定。明确给出不知道什么、为什么不知道、这会妨碍什么。不能只添加这些词就授予重要性，也不能复用旧论文的空白声明作为当前事实。

## 3. 强化必要性与表达力度

采用用户要求：凝练、醒目、自信地表达研究意义；将结果呈现为认识上的推进；减少执行过程和次要设置；保留清楚的特色和代表性定量发现。

具体区分：

- 科学意义可以高于单个变量的描述层级，例如从物性续接对照上升到标定模型的解释可靠性，但这种意义必须由所显示的比较推导。
- 文稿可以强调当前研究设计的独特贡献与用途，不需要在每句后追加免责条件。必要的范围在影响判断处集中表达。
- “本工作值得做”需要先前方案为什么没有回答这项具体问题、当前设计为何能提供新信息。无需声称只有本工作能解决，或其他研究全部无效。
- 不把未测热场称为物理验证，不把过去已有发现称为首次，不虚构缺陷降低、组织改善、控制效果或多材料适用性。
- 吸引力来自真实矛盾与解决思路。当前四角对照没有把每个分支重新拟合到相同几何，不能在摘要声称本研究展示了几何拟合相近却热场不同的参数组合。Myers 已观察到这种现象，支持几何拟合不能充分约束热场这一背景；本文增量须由自身实际比较建立。

用户所说“摘要不一定完全跟正文匹配”在执行中解释为：摘要不用逐节复述、不列出全部工况/参数/副要结果，篇幅比例也不必与正文相同。背景可以比本研究对象更广。摘要的目标、方法性质、核心结果和主要意义则必须能够由正文兑现。

## 4. 摘要的本稿表达选择

采用 **背景及用途—明确困难—工作特色—回答困难的主发现—意义** 的连贯段落，不机械规定句数。

| 摘要部分 | 本稿需要做的事 | 本稿应压缩的内容 |
|---|---|---|
| 背景 | 说明热过程可靠解释对 AM 研究/建模的价值 | 空泛行业发展与大范围未做工作的承诺 |
| 困难 | 点明几何约束与热状态解释之间的落差，衔接具体待分辨问题 | 开头直接列熔池 L/W/D、各物性和运行清单 |
| 本工作 | 突出受控比较为何能提供信息，例如将标定与物性响应分开判断 | 过细 solver、网格、源参数位数和全部设置 |
| 主发现 | 选少数最关键的发现与定量锚，说明它们回应了哪个困难 | 摘要里逐项搬运全部误差、支路数字和次要诊断 |
| 意义 | 写清模型认识/比较方式改变了什么 | 未验证的生产收益、普适因果或泛泛“提供参考” |

特色不是多挂形容词。每项特色应有“面对的困难—设计动作—新增的信息”。每个主结果应有“原来难以判断的内容—本工作区分的内容”。不以删掉所有数字营造高级感，不写一篇只有背景与愿景、没有实际发现的摘要。

摘要由科学编辑与引言负责人重点共同修订，再让结果/讨论负责人核对承诺。可以比技术章稿多花表达设计精力；不机械地每个章节分配相同预算。

当实际数量不足，要检查尚未展开的背景、近邻差异、方法依据、机制解释和相反证据并继续研究，而不是只宣告“避免堆砌”。若官方 ceiling 或真实范围冲突确需调整，要给出具体理由和尚有缺口，不能擅自恢复为只用十三篇。

深度对标需在文稿中表现出来：讲清多个研究路线的已知结果与条件、差异产生的原因、本设计利用的认识、以及对解释的支持/挑战。重要来源的分析不能用一串括号引用代替。摘要与引言最终凝练的是充分研究后的知识关系；研究过程可以广，正文表达应有选择。

## 6. 对协作合同的修正

科学编辑维护 `field_challenge / literature_gap / study_response / distinctive_value`，并把内部 technical question 单独保存。前三者先作为有来源的候选定位，近期文献可能使其改写，不能早期冻结为必须证明的结论。

引言负责人的交付增加：宽层定位、已知与未知的证据、各研究路线的比较、从困境到本研究的收束、陈述式 gap 候选。与讨论负责人检验是否仍成立，再进入章稿。

期刊学习任务增加：近期可比样本的 reference 数量与引用功能、摘要开头/结尾、引言推进、特色表达、各节分析颗粒度。给具体原文位置和迁移建议，不用摘要词汇黑名单或万能模板评审。

全文评阅检验两种缺陷：工作有证据但必要性说不清；表达很宏大但正文承诺落空。保持既有数值证据的真实身份，在最终整合时同时修订标题、摘要、引言、讨论和结论。
